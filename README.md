## Overview

An immersive, conversion-optimized landing page designed to transform visitors into registered retreat participants. The retreat **"You Can Heal Your Life"** offers a 3-day experiential journey at one of the most sacred energy vortexes on the planet — **Mount Shasta, CA** — guided by hypnotherapist **Isabela Owl**, facilitated through the methodology of Louise Hay.

The site is fully bilingual (Spanish & English), targeting both the U.S. Hispanic community and the broader English-speaking California market.

## Key Features

```
Bilingual architecture  —  ES / EN toggle in navbar (desktop + mobile)
Conversion-focused      —  5 strategically placed CTAs + urgency mechanics
Premium UX              —  Parallax hero, glassmorphism cards, AOS scroll animations
Zero build process      —  Pure HTML + Tailwind CDN, deployable in seconds
CCPA / CPRA compliant   —  Full Privacy Policy modal for California residents
WhatsApp integration    —  Floating CTA + pre-written localized message strings
Fully responsive        —  375px → 2560px, mobile-first grid system
```

## Customization

**Update contact details** — search and replace in both HTML files:
```
+1 (408) 800-9376          →  your WhatsApp number
mundoholisticousa@gmail.com  →  your email address
```

**Update theme colors** — edit the Tailwind config block inside each HTML file:
```javascript
tailwind.config = {
  theme: {
    extend: {
      colors: {
        primary:  '#YOUR_COLOR',
        accent:   '#YOUR_COLOR',
        contrast: '#YOUR_COLOR',
      }
    }
  }
}
```
